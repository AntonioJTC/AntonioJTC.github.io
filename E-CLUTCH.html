¿Qué es Honda E-Clutch?

Honda E-Clutch es un sistema que controla electrónicamente el embrague de una motocicleta con cambio manual. Permite iniciar la marcha, cambiar de velocidad y detenerse sin accionar la maneta de embrague.

El conductor continúa seleccionando las marchas con el pedal. El sistema se encarga de gestionar el embrague durante esas operaciones.

¿Cómo funciona?

El sistema combina sensores, control electrónico y pequeños motores eléctricos para accionar el embrague. Su funcionamiento puede resumirse en tres pasos:

  1. Recoge información. Los sensores detectan datos como las revoluciones, la posición del acelerador, la marcha engranada y la presión sobre el pedal de cambio.
  2. Calcula la intervención. Las unidades electrónicas coordinan el control del motor y del embrague según la situación.
  3. Acciona el embrague. Los actuadores eléctricos ajustan su funcionamiento para realizar la operación solicitada.

¿Cuándo interviene?

Al iniciar la marcha

Gestiona el acoplamiento del embrague para salir desde parado sin utilizar la maneta.

Al cambiar de velocidad

El conductor acciona el pedal para subir o bajar una marcha y el sistema coordina la intervención del embrague.

Al detenerse

Controla el desacoplamiento del embrague durante la parada, sin exigir que el conductor apriete la maneta.

Embrague manual, E-Clutch y DCT

La diferencia principal está en qué operaciones realiza el conductor y cuáles automatiza el sistema.

Comparación del control del embrague y las marchas
Sistema Control del embrague Selección de marchas
Manual convencional El conductor utiliza la maneta para las operaciones habituales. El conductor utiliza el pedal.
Honda E-Clutch Control electrónico, con posibilidad de intervención manual. El conductor utiliza el pedal.
Honda DCT Control automatizado de dos embragues. Puede seleccionar las marchas automáticamente o permitir la selección manual.

¿Se puede seguir utilizando la maneta?

Sí. El conductor puede intervenir utilizando la maneta incluso con el control electrónico activado.

También puede desactivar el sistema. En ese caso, debe manejar el embrague como en una motocicleta manual convencional.
